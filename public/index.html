    About the archive

    The server searches <folder>\YYYY\DDD\*.LOG (DDD = day of year) for ITDETECTSTATUS and BESTPOS/BESTSATS reports and reads one file at a time. BESTPOS supplies satellite count and fix type; BESTSATS supplies a satellite-count fallback only. Each file is summarised once and cached locally, so reloading or extending the range only reads new files (about 400 MB per day the first time). Archive data is drawn with hollow markers and dashed lines beneath the live data. With Keep loaded on, the server reloads the selected days every few minutes so the archive window rolls forward; the NAS receives each hourly file hours late, and the server keeps 24 hours of live history to cover those newest hours. Choose History: 24 hours to see the whole day combined. An unreachable NAS times out and is retried later.

    How to use these plots

    Use View to jump to a time range; the arrows pan and −/+ zoom. Drag any plot to pan; scroll to zoom around the pointer. Turn on Select point to click a data point and pin its details instead of panning; press Esc or the button again to go back to panning. All plots share the same time window and selected time zone. Signal buttons toggle frequency overlays only; detected energy remains visible in red. Overlapping allocations use alternating colour stripes; hover for full signal bounds. The bottom two rows show satellites used in the BESTPOS solution and its fix type (live and saved history only).
